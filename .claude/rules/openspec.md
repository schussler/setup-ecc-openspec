# Regra: Integração com OpenSpec

1. Sempre que receber um comando para implementar uma funcionalidade, comece lendo:
- `openspec/specs/` (para entender o estado atual do sistema)
- `openspec/changes/<change-atual>/tasks.md` (para saber o próximo passo exato)
2. Não desvie dos contratos de schema definidos nas especificações.
3. Se encontrar inconsistências entre a especificação e o código existente, aponte antes de alterar.
